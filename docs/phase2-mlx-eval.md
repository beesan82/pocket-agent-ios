## 測定 1（2026-10-19、TestFlight フィードバック ACJuQ0hPNSuq の測定サマリーより）

| 項目 | 値 |
|---|---|
| 端末 / iOS | iPhone15,4（iPhone 15）/ iOS 26.6.2、ja-JP、Wi-Fi、電池 80% |
| ビルド | 0.0.1 (5) |
| モデル | **Qwen3 1.7B (4bit)**（既定の Qwen2.5 ではなく、こちらが選択されていた） |
| 状態 | ダウンロード済み / **メモリ不足で解放**（測定中のどこかでメモリ警告） |
| 読み込み時間 | 0.6 秒 |
| メモリ | activeMemory 読込前 0 MB → 読込後 923 MB、os_proc_available_memory 2972 MB |
| 短文（66 字） | 26.3 秒、19.4 tok/s、見出しなし |
| 中文（321 字） | 25.0 秒、20.5 tok/s、見出しなし |
| 長文（908 字） | 30.0 秒、17.0 tok/s、見出し「月曜日の過ごし方」 |
| 音声 | 利用可能（SpeechTranscriber ja-JP が iPhone 15 で動作）、30 秒テストで 86 字 |

### 所見
- 生成速度は約 20 tok/s。短文でも約 500 トークン（maxTokens 512）を消費しており、Qwen3 の thinking 出力が上限を食っていると推定（見出し欠落とも整合）。設計どおり、thinking 無効化が確認できない Qwen3 は既定にしない。
- **音声入力は Apple Intelligence 非対応の iPhone 15 でも利用可能**（AT-02 の前提の一部を実機で確認）。
- メモリ警告の発生時点は未特定。次回 Qwen2.5 で再測定し、警告時の操作をコメントで記録する。
- 要約本文の品質は未確認（スクリーンショットにはサマリーのみ）。

### 次回
- Qwen2.5 1.5B を選択して同じ手順で再測定し、要約結果の部分も別スクショで送る。

## 既定モデルの判断（2026-10-19）

| 項目 | 内容 |
|---|---|
| 既定モデル | **mlx-community/Qwen2.5-1.5B-Instruct-4bit** |
| 理由 | iPhone 15 で長文 908 字でも 12 秒、メモリ警告なし、指定の「見出し:」形式に従う。日本語を公式サポート。 |
| 見送った候補と理由 | Qwen3 1.7B: thinking 出力で maxTokens を使い切り 25〜30 秒・見出し欠落、測定中にメモリ警告。thinking 無効化を確認できるまで既定にしない。 |
| 残課題 | 要約本文の品質は未確認（日誌画面の実使用で確認）。短文の見出しが本文の書き出しになりがち → 見出し指示を Task 9/10 で調整。 |
