# 実機検証手順: 「記録」タブへの統合

日付: 2026-10-26。結果欄が埋まるまで実機動作は未確認。

## 手順

1. 下部タブが「記録」「チャット」の二つであることを確認する。既存の日誌と会議が記録一覧に並び、検索・詳細表示が使えることを確認する。
2. 記録タブから文字メモと短い音声メモを一件ずつ保存し、一覧に現れることを確認する。
3. 「会議の準備・言語」で言語を変更して戻り、「会議を開始」を押す。保存した言語で録音が始まることを確認する。
4. 録音中に記録一覧へ戻り、「会議に戻る」を押す。文字起こしが続き、同じ会議へ戻れることを確認する。チャットへ移動して戻る場合も確認する。
5. 会議を終了する。記録一覧へ戻ると、新しい会議が表示されることを確認する。
6. 録音中に電話などで中断させ、既存の「再開」導線を確認する。保存が失敗した場合は記録一覧に「会議の保存を再試行」が出て、会議画面で再試行できることを確認する。
7. 新しい端末または権限・音声データがない状態で「会議を開始」を押し、理由と準備操作が表示されることを確認する。
