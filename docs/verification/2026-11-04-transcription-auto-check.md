# 文字起こし精度チェック自動化の実機確認（2026-11-04）

目的: 合成音声の自動チェック（ADR-044）が実機で完走し、手動チェックと同じ物差しで CER が出ることを確認する。実認識は CI では検証できないため、この手順で人が確認する。

前提:

- TestFlight の最新ビルド（自動チェックを含むもの）を iPhone 15 に入れる。
- 音声は同梱の合成音声のみ。実音声は使わない。測定ログには件数と CER だけが残り、本文は残らない（ADR-026）。

## 手順

1. 検証画面 →「文字起こし精度チェック」で「自動チェック」を押す。A→B→C の順に進捗が出て、各文の CER と認識テキストが表示されること。
2. 測定ログに `cer.journal passage=A cer=… ref=… hyp=… src=synth` の形で 3 行残ること。本文が含まれていないこと。
3. 機内モードで（認識資産の導入が済んだ状態で）もう一度押し、完走すること。
4. 手動の読み上げチェックが従来どおり動くこと（録音 → 停止 → CER、ログ行に `src=synth` が付かないこと）。
5. 可能なら、認識資産を入れる前の状態で「自動チェック」を押し、導入が走るか、理由のあるエラー表示になること。
