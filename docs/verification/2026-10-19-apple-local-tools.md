# 実機検証手順: メモツールの呼び出し（第1段階）

**結果が出るまで未検証。** この表が埋まるまで、実機で動作したとは報告しない。

## 目的
- TestFlight フィードバック AC1tJM9i2a7w（iPhone 18,5 / iOS 27.0、ビルド 5）で報告された、Apple ローカルでメモが保存されない問題への対処を実機で確かめる。
- 対象は ADR-027（毎ターン注入）、ADR-028（救済と「メモ非対応」表示）、ADR-009（Apple ローカルへのツール配置）。
- 設計: docs/superpowers/specs/2026-10-19-agentic-tools-all-models-design.md（D6）

## 前提
- このブランチを含むビルドを TestFlight から入れる（手順は docs/testflight-setup.md）。
- Apple Intelligence が有効な端末。
- iPhone 15 では Apple ローカルの行は選べない。その端末では Claude で 手順 4 だけ試す。

## 手順
各手順の前に、MLX 検証画面の測定ログをコピーしておくと、前後の差分が取りやすい。

1. Apple ローカルを選び、「私の名前はケイタ 覚えておいて」と送る。
   - 期待: 承認シートが出る。承認するとメモが保存され、メモ一覧に載る。
   - 期待（呼べない場合）: 返信に JSON が書かれても救済されて承認シートが出る。または「メモ非対応」表示が出る。保存済みと偽らない。
2. 新しい会話を開き、Apple ローカルのまま「私の名前は？」と送る。
   - 期待: 注入されたメモから「ケイタ」と答える。ツール呼び出しは不要。
3. 「ケイタをケイタさんに直して」と送る。
   - 期待: `edit_note` が呼ばれて承認シートが出る。または返信本文の JSON が救済されて承認シートが出る。
   - 承認後、メモ一覧が「ケイタさん」に変わる。拒否したら何も変わらない。
4. 追加: Claude に切り替え、新しい会話で「私の名前は？」と送る（手順 1 で Apple ローカルに保存した後）。
   - 期待: system メッセージの注入から答える。Claude 選択中は「メモ非対応」表示が出ない。

## 結果の読み方
- MLX 検証画面の測定ログを開く。
- `toolcall.native` / `toolcall.rescued` / `toolcall.ambiguous` / `toolcall.none` の各行を数える。
- 形式: `toolcall.<種別> model=<raw>[ tool=<name>]`。
- `native` が増えれば FoundationModels がツールを直接呼べている。`rescued` が増えれば本文 JSON の救済が働いた。
- `none` だけが続く場合は、メモ意図の発話でもツールが呼ばれていない。
